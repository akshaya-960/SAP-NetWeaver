# SAP NetWeaver BASIS Admin Lab

End-to-end build of a single-system SAP NetWeaver AS ABAP landscape on a personal VM, documented through the full BASIS admin lifecycle: installation, config, user/auth management, transports, client admin, monitoring, backup/recovery, and patching.

## Phases

- [ ] 01 - Landscape Planning
- [ ] 02 - Installation
- [ ] 03 - Post-Install Configuration
- [ ] 04 - User & Authorization Management
- [ ] 05 - Transport Management (STMS)
- [ ] 06 - Client Administration
- [ ] 07 - Monitoring & Performance
- [ ] 08 - Backup & Recovery
- [ ] 09 - Stretch: Support Packages / Kernel Patch (SPAM/SAINT)

Each phase folder under `docs/` has the write-up, screenshots, and any errors hit plus how they were fixed.
